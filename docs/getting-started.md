# Getting started

## Clone

```bash
git clone https://github.com/Aimerrhythme/ee-lab-toolkit.git
cd ee-lab-toolkit
```

## Python environment

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## MATLAB path

```matlab
addpath(genpath('tools'));   % from repo root
```

## Run the first available demo

After the first tool lands under `tools/`, open its README and run the listed demo command.
